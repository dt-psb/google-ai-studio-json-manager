공식 사용설명서 & 가이드북

Google AI Studio 대화 세션 & 브랜치 계통도 완벽 활용 가이드

수백 개의 질문과 답변으로 이루어진 방대한 대화를 파일 하나에 끝없이 담지 않고, Git 브랜치처럼 가지치기하고 부모-자식 간 공통 설정을 완벽하게 동기화할 수 있는 차세대 프롬프트 매니저입니다.

1. 개요 & 탄생 배경

Google AI Studio를 사용할 때 가장 큰 고충 중 하나는 "대화가 너무 길어져 파일이 무거워지고, 여러 갈래의 스토리를 시험해보고 싶은데 파일이 분리되면 앞부분 설정 수정사항이 연동되지 않는 것"이었습니다.

기존의 문제점

  • 파일 하나가 수백 개 청크로 불어나 스크롤과 로딩이 극도로 느려짐
  • 새 아이디어를 시험하려고 '다른 이름으로 저장'하면 앞부분 세계관 설정이 나중에 수정되었을 때 수동으로 복붙해야 함
  • 수십 개의 파일이 어디서 갈라져 나왔는지 계통을 전혀 알 수 없음

AI Studio Manager의 해결책

  • Branch Off: 원하는 대화 청크 지점에서 새 분기 파일 생성
  • 상속 계통도: 공통 부모 대화는 접어두고 내 고유 대화만 쾌적하게 작성
  • 원클릭 동기화: 부모 내용을 바꾸면 수십 개 하위 분기 파일도 자동 일괄 교체

2. 메인 인터페이스 구조

화면은 작업 효율성을 극대화하기 위해 3단 반응형 구조로 설계되어 있습니다.

1. 좌측 보관함 사이드바

로컬 `storage/` 폴더 내의 모든 JSON 파일과 하위 폴더를 트리 형태로 표시합니다. 우클릭 컨텍스트 메뉴로 메모장 열기, 폴더 열기가 지원됩니다.

2. 중앙 메인 스테이지

대화창 피드(Feed), 대화 계통도 트리(Tree), 검색 전용 세션(Search)을 상단 탭으로 자유롭게 전환합니다.

3. 우측 네비게이터 & 하단 입력창

우측 세로 도트 레일로 원하는 청크로 순간 점프하며, 하단 대기열 입력창을 통해 새 청크를 즉시 추가합니다.

패널 경계선(좌측 패널 우측 경계, 하단 입력창 상단 경계)을 마우스로 드래그하여 높이와 너비를 자유롭게 조절할 수 있습니다.

3. 청크 에디터 & 도트 레일

✨ 청크 카드의 핵심 조작법

USER MODEL THINKING
역할(Role) 원클릭 순환 변경

청크 상단의 역할 뱃지를 클릭하면 즉시 User ➔ Model ➔ Thinking 순서로 변경됩니다.

옵시디언 설정 덤프 스마트 분리
10만자 Lorebook 자동 감지

청크 내에 방대한 설정(#, ## 마크다운 헤더)이 포함되어 있으면 상단에 [설정 청크로 분리] 배지가 뜨며, 본문과 지시 프롬프트를 깔끔하게 분리할 수 있습니다.

우측 퀵 점프 도트 레일 (네비게이터) 넛지 가이드

우측 끝의 세로 레일은 수십 개의 청크를 스크롤 없이 원클릭으로 탐색하게 돕습니다. 도트의 모양(원형 vs 마름모)과 색상으로 대화의 성격을 한눈에 직관적으로 파악할 수 있습니다.

호박색(앰버-골드) 마름모 도트 분기점 (Branch Fork)

현재 파일의 이 청크에서 다른 대화 파일들로 갈라져 나간 분기점입니다. 마우스를 올리면 [🌿 분기점: N개 갈라짐] 툴팁과 분기된 파일명이 보이며, 클릭 시 해당 지점의 분기 배너를 즉시 펄스 하이라이트합니다.

보라-인디고(바이올렛) 마름모 도트 고유 대화 분기 시작점

상위 부모 세션으로부터 이 파일이 분기되어 시작된 첫 번째 고유 청크 지점입니다. 상속받은 부모의 공통 대화 구간(#1~#N)이 끝나고, 현재 파일만의 고유한 대화가 시작되는 중요한 경계선을 은은하게 넛지해 줍니다.

원형 도트: 일반 대화 청크 (파랑 = USER, 초록 = MODEL, 보라 = THINKING, 반투명 테두리 = 상속된 공통 대화)

4. 브랜치 분기 (Branch Off)

대화가 진행되다가 "여기서 다른 선택을 했다면 어땠을까?" 혹은 "이 시점에서 외전이나 다른 루트로 이야기를 전개하고 싶다"는 생각이 들 때 사용하는 기능입니다.

가지치기 분기 3단계 흐름

Step 1. 청크 선택

갈라져 나가고 싶은 청크 카드의 우측 상단 툴바에서 [🌿 가지치기 (Branch Off)] 아이콘을 누릅니다.

Step 2. 파일명 입력

모달 창이 뜨면 새로 만들 파일 이름(예: `chat_route_b.json`)과 저장할 폴더를 지정합니다.

Step 3. 즉시 생성 & 전환

선택한 청크까지의 모든 공통 대화가 자동으로 복제된 새 파일이 생성되며, 즉시 해당 파일로 전환됩니다.

5. 부모-자식 양방향 대화 연동 (Sync Engine)

파일이 분기된 이후 "부모 파일의 앞부분 설정을 고쳤을 때 다른 자식 파일들도 자동으로 연동되는가?"에 대한 완벽한 솔루션입니다.

부모 파일에서 ➔ 하위 자식 세션들에 일괄 연동

부모 파일의 대화 내용을 수정한 후 상단 배너의 [하위 세션 N개에 일괄 연동] 버튼을 누르면, 이 부모를 공유하는 모든 자식 파일의 공통 구간(#1~#N)이 최신 내용으로 자동 교체됩니다.

✅ 자식 파일 각각의 고유 대화는 100% 보존되며 공통 부모 파트만 교체됩니다.
자식 파일에서 ➔ 최신 부모 내용으로 연동

자식 파일을 열었을 때 부모 파일이 수정되어 내용이 달라졌다면, 상단에 [부모 내용 변경됨] 경고 뱃지가 뜹니다. 우측의 [🔄 최신 부모 내용으로 연동]을 누르면 최신 부모 대화로 즉시 갱신됩니다.

💡 상속된 조상 청크는 평소에 [접기] 상태로 숨겨두어 내 고유 대화에만 몰입할 수 있습니다.

6. 대화 계통도 트리 맵 (3대 뷰 모드)

상단 탭에서 [대화 계통도 트리]를 선택하면 보관함의 모든 파일들의 혈통 관계를 시각적으로 탐색할 수 있습니다.

대화 유형 필터 (독립 단일 대화 따로 보기)

수십 개의 파일 중 가지치기된 대화와 단일 대화를 원클릭으로 분리합니다.

전체 🌳 분기 계통 대화만 🌱 독립 단일 대화만
🌲

1. 세로 계층형 트리 (Vertical)

클래식한 인덴트 트리 구조입니다. 자식 파일이 직계 부모의 몇 번 청크에서 갈라져 나왔는지(#N) 상세 딥링크와 Diff 분석 버튼을 함께 제공합니다.

특징: 직관적인 부모-자식 인덴트 계층
🌿

2. 가로 분기 마인드맵 (Mindmap)

부모 노드 바로 오른쪽에 직계 자식 노드들이 화살표로 매핑되는 마인드맵형 브랜치 파이프라인입니다. 71개 등 세션이 많을 때 [▾ 하위 N개 접기/펼치기]로 원하는 가지만 깔끔하게 펼쳐볼 수 있습니다.

특징: 부모-자식 직결 & 하위 가지 접기 지원
▦

3. 카드 그리드 대시보드 (Grid)

각 계통도를 3열 바둑판식 카드로 배치한 대시보드 뷰입니다. 세션이 6개를 초과하면 [더보기 아코디언]으로 깔끔하게 접어두어 갤러리처럼 조망할 수 있습니다.

특징: 갤러리형 요약 & 대량 세션 접기

7. 세계관(Worldview) 관리 시스템

대화가 많아질수록 "이 대화는 SF 세계관인가, 판타지 세계관인가, 일상물인가?"를 태깅하여 분류하는 기능입니다.

세계관 배정 및 필터링 방법
  • 상단 알약(Pill) 버튼: 원하는 세계관 알약을 클릭하면 해당 세계관에 속한 대화들만 즉시 필터링됩니다.
  • 계통도 드롭다운: 계통도 카드 상단의 [세계관: ...] 드롭다운을 눌러 계통도 전체를 한 번에 특정 세계관으로 배정할 수 있습니다.
  • 세계관 관리자 모달: 상단 [세계관 관리] 버튼을 눌러 새 세계관을 추가하거나 순서를 드래그 앤 드롭으로 바꿀 수 있습니다.

8. 보관함 & 외부 툴 연동

좌측 사이드바의 보관함 트리에서 파일이나 폴더를 마우스 우클릭하면 강력한 빠른 작업 메뉴가 열립니다.

메모장으로 바로 열기

Windows 기본 메모장(Notepad)으로 JSON 파일을 즉시 열어 원본 코드를 확인하고 편집합니다.

탐색기에서 파일 / 폴더 열기

해당 파일이 위치한 실제 윈도우 파일 탐색기를 열고 해당 파일을 포커스합니다.

9. 단축키 & 문제 해결 FAQ

주요 단축키 모음

기능 단축키 설명
대화 저장 Ctrl + S 현재 대화 내용을 storage 폴더에 즉시 저장합니다.
청크 삭제 취소 (복구) Ctrl + Z 휴지통에서 방금 삭제한 청크를 제자리에 되돌립니다.
대기열 전송 Ctrl + Enter 하단 입력창에서 새 청크를 즉시 피드에 추가합니다.
전체 새로고침 F5 UI 화면을 최신 상태로 새로고침합니다.
Q. 부모 내용을 연동할 때 자식 파일에서 내가 덧붙인 대화가 날아가나요?

절대 날아가지 않습니다! 알고리즘이 부모와 자식 간의 공통 접두 청크 구간(#1~#N)만 정확히 식별하여 교체하며, 자식 파일의 고유 대화는 1글자도 유실되지 않고 안전하게 보존됩니다.

Q. 71개 세션처럼 분기가 너무 많은 계통도는 어떻게 보나요?

[가로 분기 트리] 보기에서 계통도 상단의 [모두 접기]를 누르면 루트 1개만 남아 한눈에 조망할 수 있으며, 카드 하단의 [▾ 하위 N개 펼치기]를 통해 내가 보고 싶은 가지만 쏙쏙 열어볼 수 있습니다.
