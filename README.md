# Google AI Studio Prompt & Chunk Manager

Google AI Studio에서 내보낸(Export) JSON 파일을 마치 AI Studio 웹 인터페이스처럼 직관적으로 시각화하고, 청크 단위로 자유롭게 편집, 복제, 복사/붙여넣기 및 관리할 수 있는 도구입니다.

---

## 🚀 빠른 시작

### 방법 1: 🖥️ 독립 데스크톱 프로그램으로 실행 (추천 ⭐)
웹 브라우저를 띄우지 않고, 주소창/탭 없는 깔끔한 **전용 데스크톱 창 앱**으로 실행합니다.
* **사전 준비**: PyQt5 라이브러리가 필요합니다. (터미널에서 1회 설치)
  ```bash
  pip install -r requirements.txt
  # 또는
  pip install PyQt5 PyQtWebEngine
  ```
* 실행:
  * **`launch_app.vbs`** 더블 클릭 (검은 콘솔 창 없이 즉시 조용히 실행)
  * 또는 **`launch_app.bat`** 더블 클릭 (배치 파일로 실행)
  * 또는 **`app.pyw`** 더블 클릭 (파이썬 윈도우 런처로 직접 실행)

> **데스크톱 프로그램 단축키:**
> * `F5` / `Ctrl + R` : 새로고침
> * `Ctrl + Shift + R` : 캐시 무시 강력 새로고침
> * `F12` : 개발자 도구 (DevTools 창)
> * `F11` : 전체화면 토글
> * `Ctrl +` / `Ctrl -` / `Ctrl 0` : 화면 확대 / 축소 / 기본 크기
> * 파일 다운로드 시 내 PC의 `C:\Users\<사용자명>\Downloads` 폴더에 즉시 저장 연동

### 방법 2: 웹 브라우저로 실행 (`run.bat`)
* **추가 패키지 설치 필요 없음!** Python 3 기본 내장 표준 라이브러리만으로 100% 구동됩니다.
* 폴더에 있는 **`run.bat`** 파일을 더블 클릭합니다.
* 자동으로 로컬 파이썬 서버가 시작되며 기본 웹 브라우저(`http://localhost:8500/index.html`)가 열립니다.

### 방법 3: `index.html` 단독 실행
* **파이썬 설치조차 필요 없음!** 오프라인 환경에서도 **`index.html`** 파일을 더블 클릭하면 브라우저 전용 로컬 뷰어로 바로 열립니다.

## 🌟 주요 기능 및 최신 업데이트

### 1. 가독성 높은 모던 폰트 적용
* 본문: **Pretendard** (한국어 및 영문 모두 최상의 가독성을 제공하는 모던 산세리프 폰트)
* 코드/수치/JSON: **JetBrains Mono** (가독성과 심미성이 뛰어난 개발자 전용 고품질 모노스페이스 폰트)

### 2. 눈이 편안한 12종 다채로운 테마 시스템
기존의 눈부신 순백색 라이트 모드 대신, 눈의 피로를 최소화하고 작업 몰입도를 극대화하는 12가지 테마를 제공합니다.
* **🌙 Dark Studio (기본)**: Google AI Studio 스타일의 정갈하고 차분한 모던 다크 테마
* **🌌 Midnight Navy**: 세련되고 깊이감 있는 심해 딥 네이비 블루 테마
* **🌲 Forest Emerald**: 장시간 텍스트를 읽어도 눈이 편안한 차분한 에메랄드 숲 테마
* **❄️ Nordic Slate**: 북유럽 감성의 단정하고 정돈된 슬레이트 블루-그레이 테마
* **🔮 Cyberpunk Violet**: 신비롭고 감각적인 네온 바이올렛 다크 테마
* **🖤 OLED Pure Black**: 배터리 절약과 극상의 명암비를 제공하는 완전한 칠흑의 블랙 테마
* **📜 Warm Paper (눈 편한 세피아)**: **눈부심 없는 따뜻한 종이/전자책 리더기 질감의 크림 베이지 라이트 테마 (추천)**
* **☀️ Clean Studio Light**: 산뜻하고 깔끔한 모던 화이트 스튜디오 라이트 테마
* **🌹 Rosé Noir**: 와인빛 붉은 기운이 감도는 매혹적이고 우아한 다크 테마
* **🌊 Abyss Teal**: 신비로운 심해의 청록빛 틸 다크 테마
* **🔥 Amber Ember**: 따뜻한 모닥불 잿불과 앰버 골드빛의 아늑한 다크 테마
* **🌸 Sakura Mist**: 화사하고 부드러운 벚꽃 핑크빛 소프트 라이트 테마
* 상단 헤더의 테마 셀렉터(`🎨`)에서 즉시 전환 가능하며, 브라우저 로컬 저장소 및 서버에 자동 기억됩니다.

### 3. 모든 청크 개별 접기/펼치기 & 한 줄 요약 프리뷰
* **Thinking, User, Model 청크 모두** 각 청크 헤더 좌측의 접기/펼치기 화살표(`▼`/`▶`)로 자유롭게 접을 수 있습니다.
* 청크가 접히면 본문은 숨겨지고 헤더에 **첫 문장 한 줄 미리보기 요약**(`"..."`)이 깔끔하게 표시됩니다.
* **Thinking 청크 기본 접힘**: 긴 사고 과정(CoT) 블록은 파일 로드 시 자동으로 닫힌 상태로 시작합니다.
* **상단 툴바 `[모두 접기 / 모두 펼치기]` 버튼**: 수십 개의 긴 청크도 클릭 한 번으로 목차처럼 요약하거나 전체를 펼칠 수 있습니다.

### 4. 마크다운 본문 더블클릭 편집 제거 (텍스트 선택 편의성 개선)
* 마크다운 본문을 마우스로 드래그하거나 더블클릭할 때 의도치 않게 편집창으로 바뀌던 불편함을 완전히 제거했습니다.
* 이제 텍스트를 편안하게 선택하고 복사할 수 있으며, 편집이 필요할 때는 각 청크 헤더의 **연필 아이콘(`✏️`)** 또는 상단 툴바의 **`[텍스트 편집 모드]`** 버튼으로 안전하게 전환합니다.

### 5. JSON 파일명 변경 기능
* 상단 헤더의 파일명(`불러온 파일 없음` 또는 `Google AI Studio 테스트.json`) 옆 **연필 아이콘(`✏️`)**을 클릭하면 파일명 변경 모달이 열립니다.
* 새 이름을 입력하면 상단 표시명은 물론, **로컬 서버 파일 이름 변경** 및 **저장/다운로드 파일명**에 즉시 연동됩니다.

### 6. 스텝 슬라이더 & 퀵 점프 틱 레일 (Snap Tick Rail)
청크가 많은 긴 대화에서도 원하는 지점으로 눈 깜짝할 새 이동할 수 있습니다.
* **우측 플로팅 틱 레일**: 피드 우측에 청크별 미니 도트(User: 파랑, Thinking: 보라, Model: 초록)가 배치되어 마우스를 올리면 청크 번호와 요약 말풍선이 뜨며, 클릭 시 부드럽게 해당 청크로 스크롤 점프합니다.
* **상단 스텝 슬라이더 & 이동 버튼**: 툴바의 슬라이더를 당기거나 `▲`/`▼` 버튼을 눌러 청크 단위로 즉시 점프할 수 있습니다.

### 7. 우측 세팅창(너비) 및 하단 프롬프트창(높이) 마우스 드래그 조절
* **우측 Run Settings 패널**: 왼쪽 경계선을 마우스로 잡고 좌우로 드래그하여 패널 너비(240px ~ 750px)를 자유롭게 늘리거나 줄일 수 있습니다.
* **하단 Pending Input 바**: 상단 경계선을 마우스로 잡고 위아래로 드래그하여 입력창 높이(85px ~ 480px)를 조절할 수 있습니다. 장문의 프롬프트를 작성할 때 시원시원하게 넓혀서 사용할 수 있습니다.
* 조절한 창 크기는 브라우저 로컬 저장소에 기억됩니다.

### 8. 화면 고정 레이아웃 & 청크 사이 인터랙티브 삽입
* 상단 헤더/툴바와 하단 프롬프트 바가 항상 화면에 고정되며, 중앙 피드만 독립 스크롤됩니다.
* 청크와 청크 사이에 마우스를 올리면 `[+User] [+Model] [+Thought]` 팝업이 나타나 중간에 원하는 청크를 즉시 끼워 넣을 수 있습니다.

### 9. 대용량 파일 격리 보관함 (`storage/`) & 다계층 폴더 트리
* 2MB 이상의 거대한 대화 파일이 외부 AI 코딩 도구의 토큰을 과도하게 소모하지 않도록 `.gitignore` 및 `.cursorignore`로 안전하게 격리된 **`storage/`** 전용 보관함을 지원합니다.
* 좌측 사이드바에서 다계층 서브폴더 생성, 파일 분류 및 이동, 원클릭 열기를 완벽히 지원합니다.

### 10. AI Studio 대화 브랜치 관리 & Git Graph 트리 (Branch Off)
AI Studio의 "Branch off"로 갈라져 나간 여러 대화 파일들을 GitHub 브랜치처럼 시각화하고 직관적으로 관리합니다.
* **공통 청크 일치 탐지 & 패밀리 그룹화**: 초반 질문이나 대화 내용이 일치하는 파일들을 알고리즘(LCP)으로 자동 분석하여 하나의 대화 계통도(Family)로 묶어줍니다.
* **청크 카드 내 분기점 배너 (In-Feed Fork Banner)**: 피드를 스크롤할 때 다른 파일로 갈라져 나간 지점 아래에 Git 스타일 분기 배너가 표시되며, 달라진 질문/답변 미리보기와 함께 원클릭으로 해당 브랜치 파일로 즉시 이동할 수 있습니다.
* **원클릭 가지치기 (Branch Off)**: 원하는 청크의 `[🌿 분기]` 버튼을 누르면 해당 지점까지의 대화만 복사된 새로운 `.json` 파일을 보관함에 생성하고 즉시 작업 창으로 전환합니다.
* **대화 브랜치 맵 (Git Graph Modal)**: 상단 `[🌿 브랜치 맵]` 버튼을 통해 전체 대화 파일들의 계통도(Main Trunk & Branches)를 한눈에 파악하고 검색할 수 있습니다.
* **청크 분기 Diff 비교**: 두 대화 파일이 몇 번 청크까지 일치하고, 어떤 청크부터 어떻게 갈라졌는지 나란히 비교할 수 있는 시각적 Diff 모달을 제공합니다.
