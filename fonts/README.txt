# 사용자 폰트 폴더 (User Custom Fonts)

이 폴더(fonts/)에 사용하고 싶은 폰트 파일(.woff2, .woff, .ttf, .otf)을 넣으시면
Google AI Studio Manager 웹 화면의 [폰트 설정] 메뉴에서 자동으로 감지되어 즉시 적용할 수 있습니다.

[지원하는 파일 형식]
- .woff2 (가장 권장, 압축률 우수)
- .woff
- .ttf (트루타입 폰트)
- .otf (오픈타입 폰트)

[사용 방법]
1. 원하는 폰트 파일(예: D2Coding.woff2, NanumSquare.ttf 등)을 이 fonts/ 폴더에 넣습니다.
2. 프로그램 상단 헤더의 [Aa 폰트 설정] 버튼을 누릅니다.
3. 자동으로 감지된 폰트 목록에서 해당 폰트를 선택하면 본문 및 코드 전체에 적용됩니다.
4. 웹 UI에서 [폰트 파일 추가] 버튼을 눌러 브라우저에서 직접 파일을 끌어다 놓아도 이 폴더에 자동 등록됩니다.
