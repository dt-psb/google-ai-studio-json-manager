# 대용량 JSON 보관함 (Storage)
이 폴더는 대용량(2MB 이상 등)의 Google AI Studio JSON 파일들을 분류하여 모아두는 전용 보관함입니다.

[특징 및 안내]
1. AI 어시스턴트(바이브코딩 / Cursor / Antigravity 등)가 이 폴더의 대용량 파일들을 자동 스캔하거나 토큰을 낭비하지 않도록 .gitignore 및 .cursorignore로 격리되어 있습니다.
2. 이 안에서는 자유롭게 하위 폴더(이중 폴더, 다층 폴더)를 만들고 파일들을 분류 및 이동할 수 있습니다.
3. 웹 UI 좌측 사이드바의 [JSON 보관함] 트리 메뉴에서 폴더 생성, 파일 이동, 이름 변경 등을 손쉽게 수행할 수 있습니다.
